# 闇庭 — Garden of Shadows —

絵本のような庭で素材を採り、ポーションを調合するブラウザゲームです。

## 遊べること

- 9属性・600種類の素材の採取と収集
- 庭の水やり、お手入れと成長の変化
- 素材2〜3個を組み合わせるポーション調合
- レシピ図鑑、ポーションの売却、日替わり依頼
- BGM・効果音の音量設定、スマートフォンの縦画面対応
- ブラウザ内の保存と引き継ぎコードの書き出し・読み込み

## 起動

`index.html`と`night-bgm.mp3`を同じフォルダに保存し、ブラウザでHTMLを開けます。
庭や料理の画像・CSS・JavaScript・昼BGMはHTMLに含み、夜BGMは同じフォルダのMP3から読み込みます。ビルドや外部ライブラリのインストールは不要です。
ユーザー提供のWeb版HTMLを土台に更新しています。

## 保存と連携

記録はブラウザのlocalStorageに保存します。端末やURLを変える前にゲーム内の引き継ぎコードを書き出してください。
新しい環境でコードを読み込むと続きから再開できます。
Discordとの認証・所持品同期は未実装です。ゲーム内にも案内があります。
一部の背景の操作点には、今後の実装を案内する表示が残っています。

## 公開素材

画像は提供されたHTML内の庭・調合室などの背景です。
アニメキャラクターやメンバーのペット画像、Discordのメンバー情報・本番セーブデータ・管理台帳は追加していません。
再配布ライセンスは設定していません。

## 検証

埋め込みJavaScriptの構文と背景画像8枚の読み込みを検査済みです。
ブラウザでのゲーム全操作の確認は未実施です。
GitHub PagesでのWeb配信は、リポジトリの公開範囲・利用プランに応じた別設定が必要です。


## 音と操作感の改良（1.1.0）

元の旋律を残してBGMを66BPMに調整し、高音と立ち上がりを丸くしました。
ボタンは木の短い音、水やりは水滴、採取は葉のこすれる音、調合は泡、発見は柔らかい瓶の響きで反応します。
連打や重複したクリック音は抑え、音量変化はフェードします。
設定には環境音の独立した音量と、対応端末用の軽い振動（初期状態はオフ）を追加しました。
既存セーブはそのまま読み込めます。古いセーブの設定には新項目の既定値を補います。

検証: `node audio.test.mjs`。10種類の効果音、130秒のBGMスケジューリング、旧セーブ互換、音量ゼロを検査します。
これは音声処理の構造・数値検査です。実機での聴感、振動の対応、ブラウザ上の全操作は未確認です。

## 魔法の雨（1.2.0）

「水やり」からミルクティー・レモンティー・ふつうの雨を選べます。
2枚のユーザー提供イラストをもとに、スマートフォン向けの縦長背景を画像生成で制作しました。横画面には提供イラストを使います。
静かな水音としずくの動きに合わせて庭の絵が切り替わり、約18秒後に元の成長状態の背景へ戻ります。
水やり済み・育ちきりでも雨を眺め直せます。成長タイマーの延長や短縮、素材の追加は起きません。
動きを減らす設定では降下アニメーションを止め、背景イラストで表現します。

検証: `node rain.test.mjs`。旧セーブ互換は`node audio.test.mjs`でも検査します。
実機での見え方はテスト用URLから確認し、必要に応じて調整します。

更新のたびに、最新版を遊べるテスト用URLをユーザーへの返答に必ず添えます。

## 夜の庭と焚き火（1.3.0）

左上の「🌿 庭のメニュー」から「🌙 夜にする」を選び、同じメニューの「🔥 焚き火」へ進めます。昼に戻る操作も同じ場所です。夜景はYAGPDBの既存焚き火イラストを使い、スマートフォンでは火が見える中央に合わせます。畑の成長時計は昼夜の景色と独立しています。雨は昼の庭で表示します。

YAGPDB CC544・CC546と画像台帳CC719を参照して移植しました。一般向けの既存料理16種と、通常・激辛・虹色の薪を選べます。鯖主専用料理は一般版に含めません。料理の成功3種＋焦げ共通の64枚は既存イラストを表示用に縮小し、HTML内に保存しています。人物・メンバー画像は含めません。

薪→料理→確認→焼く→取り出すの順で操作します。焼き物は1晩1回、日本時間朝5時切替。焼き始めた時点で回数を使い、素材や通貨は消費しません。早い取り出しは生焼け、焼き上がりから2分以内は大成功、2分を過ぎると焦げです。早取りは確認を挟みます。料理記録・直近50件の履歴・調理中の状態を保存し、再読込・引き継ぎでも維持します。昼に戻っても調理中の時計は進みます。二重取り出し・重複記録を防ぎます。

ブラウザ版での調整：料理ごとの元の焼き時間は管理画面のマスターが省略表示され全文取得できなかったため、初回実装では全料理60秒に統一しています。Discordは現実の17時～翌5時限定ですが、Web版は景色を夜にすると遊べます。夜の切替で日付や回数を進めません。未移植のペット好感度や協力加護の報酬は付与しません。元のYAGPDB本番コマンドとDBは変更していません。

焚き火は環境音スライダーに連動する、控えめなぱちぱち音を追加しています。元のBGMと効果音も維持します。

夜BGMは「星空のアクアリウム」（優日のすたるじっく／のすたるじっくBGM庫）。公式BOOTH https://booth.pm/ja/items/4991673 で制作物のBGM利用が許可されていることを2026年10月22日に確認しました。元動画 https://youtu.be/uTzAU7xYYqg 。1.3.1でユーザー添付の公式配布MP3を導入し、昼夜に応じた切替を実装しました。

検証：`node campfire.test.mjs`（192パターンと境界・保存・移行）に加え、既存の音楽・効果音・雨の検査を通過。プレビュー基盤が使えず、実ブラウザでの見た目・全操作・聴感は未確認です。


## 昼夜のBGM切替（1.3.1）

「庭へ入る」で、保存済みの昼夜に合った曲が流れます。庭のメニューで夜にすると「星空のアクアリウム」、昼に戻すと「旅人と古代遺跡の記憶」へ切り替わります。切替時に前の曲を停止し、2曲が同時に流れ続けることを防ぎます。BGMオフ・音量ゼロ・非表示時の停止を両方の曲に適用します。夜のまま再読込しても、入場までは再生せず、「庭へ入る」で夜の曲を選びます。

昼BGM・画像・コードはHTML内、夜BGMは同じフォルダの`night-bgm.mp3`です。GitHubの配信サイズを考慮した構成で、閲覧時にYouTubeやBOOTHへのログインは要りません。ゲーム内設定とCREDITS.mdに作者・元動画・公式配布を記載しました。音源の著作権は作者に帰属し、リポジトリから独自に再許諾しません。

検証：`node night-music.test.mjs`、既存のmusic/audio/rain/campfireテスト。実機での聴感はテストURLで確認してください。

## 焚き火の表示・通知・演出（1.3.2）

料理を選ぶ画面と焼く前の確認画面から、焼き上がりの見本画像を除きました。画像は取り出した結果と過去の料理記録だけに表示します。
焼き上がりの確認を料理画面の表示条件から分離し、庭や調合室にいても画面内通知を出します。「火のそばへ戻る」で取り出し画面へ戻れます。通知音の送信済み状態を保存するので、画面を開き直したりセーブを読み込んだりしても繰り返し鳴りません。ブラウザを閉じた状態のOSプッシュ通知ではありません。バックグラウンドから戻った時、焦げていればその状態を知らせます。

夜の庭の既存イラストに、低い透明度の炎の揺らぎ、暖色の明かり、小さな火の粉を重ねました。横画面・縦画面それぞれに配置し、30fps以内、非表示時に停止、動きを減らす設定では静かな明かりだけにします。エフェクトは画像を差し替えずCanvasで描画します。

次工程は元のCC547のドリンク（ベース→淹れ方→トッピング）・夜話・演奏です。今回これらを追加済みとは扱いません。元データの管理画面が長文を省略するため、読み取り用コピーを作る補助コマンドの保存/実行を試みましたが、自動承認レビューが永続DBへの書き込みと定期設定の明示承認不足として拒否しました。補助コードは保存/実行せず、CC733はNone・コメントのみの現行CC547原文控えにしています。利用者のゲームDBは変更していません。ドリンク画像の制作・共用URL台帳・Discord側表示も次工程です。

検証：`node cozy-fire.test.mjs`で実際の画面描画関数と通知関数を実行し、焼く前の画像なし・結果/記録の画像維持・料理画面を閉じた状態の通知・通知音の一度だけ再生・再読込・早取り/焦げの境界・動きを減らす設定への配慮を確認。既存の料理192ケース、昼夜BGM、音量・雨・セーブ互換の検査も成功。実機の見た目・聴感は未確認です。
