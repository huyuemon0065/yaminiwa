# 闇庭 — Garden of Shadows —

絵本のような庭で素材を採り、ポーションを調合するブラウザゲームです。

## 遊べること

- 9属性・600種類の素材の採取と収集
- 庭の水やり、お手入れと成長の変化
- 素材2〜3個を組み合わせるポーション調合
- レシピ図鑑、ポーションの売却、日替わり依頼
- BGM・効果音の音量設定、スマートフォンの縦画面対応
- ブラウザ内の保存と引き継ぎコードの書き出し・読み込み

## 起動

`index.html`をダウンロードしてブラウザで開けます。
背景画像8枚・CSS・JavaScriptをHTML内に含むため、ビルドや外部ライブラリのインストールは不要です。
ユーザー提供のWeb版HTMLを、そのまま保存しています。

## 保存と連携

記録はブラウザのlocalStorageに保存します。端末やURLを変える前にゲーム内の引き継ぎコードを書き出してください。
新しい環境でコードを読み込むと続きから再開できます。
Discordとの認証・所持品同期は未実装です。ゲーム内にも案内があります。
一部の背景の操作点には、今後の実装を案内する表示が残っています。

## 公開素材

画像は提供されたHTML内の庭・調合室などの背景です。
アニメキャラクターやメンバーのペット画像、Discordのメンバー情報・本番セーブデータ・管理台帳は追加していません。
再配布ライセンスは設定していません。

## 検証

ブラウザでのゲーム全操作の確認は未実施です。
GitHub PagesでのWeb配信は、リポジトリの公開範囲・利用プランに応じた別設定が必要です。
